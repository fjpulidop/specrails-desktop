## Why

The public site and mobile companion no longer explain or expose the mission-first, multi-repository Desktop workflow. Browser selection also bypasses or fails to enter annotation in some capture paths.

## What Changes

- Refresh the public product experience with a responsive, accessible, localized mission-first tour and current feature descriptions.
- Replace stale guides with current journeys, searchable navigation, explicit language fallbacks, and article-level loading.
- Add capability-negotiated mobile mission operation, repository context, reconnect recovery, and scoped process visibility while respecting paired-device grants.
- Make completed browser selections open annotation consistently before attaching to a mission.

## Capabilities

### New Capabilities
- `modern-product-experience`: Current, localized product presentation and documentation discovery.
- `mobile-mission-control`: Mobile mission interaction with version negotiation and grant-aware controls.
- `mission-capture-annotation`: Consistent selection-to-annotation handoff and recoverable attachment.

### Modified Capabilities

## Impact

Touches specrails-web marketing, guides and build checks; specrails-companion Flutter navigation, repositories and protocol; Desktop mobile gateway and browser capture UI. Preserves existing work, mobile pairing and backward compatibility. No publication or deployment is included.
