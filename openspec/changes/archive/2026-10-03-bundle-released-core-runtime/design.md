## Context

The Tauri release workflow installs the exact npm closure committed in `assemble-bundled-core.lock.json`. `CORE_BUNDLE_VERSION` must agree with that lock. Core releases are generated by release-please after main CI, then published from the verified CI tarball. The current bundle is 6.1.0; the corrected companion PR passed all 23 checks and was merged with an explicitly authorized code-owner review exception.

## Goals / Non-Goals

**Goals:** Include the newly released Core fixes in fresh Desktop installations and prove compatibility against those published bytes.

**Non-Goals:** Merge Desktop, change user installations or project data, replace retained-run runtime selection, or publish a custom Core tarball.

## Decisions

- Use Core's normal release workflow and verify that the release commit contains the merged companion fixes. Select the actual generated version only after the release is published.
- Regenerate the npm lock in an isolated temporary prefix, starting with the existing lock to retain unrelated resolutions where compatible. Update the exact bundle version alongside it.
- Pin the paired CI checkout to the immutable release commit. Use Node 22.22.3 for the Windows bundle lane, matching Core's declared minimum and the release workflow.
- Stage the registry package into the generated Tauri Core resource directory, run its CLI and contract compatibility checks, and exercise framework materialization in temporary smoke projects without touching managed user installations.

## Risks / Trade-offs

- [GitHub review or release gates block publication] → Keep gates intact unless the user explicitly authorizes the review exception; report any remaining blocker and do not fabricate a version or integrity.
- [New package changes its dependency closure] → Review the generated lock diff, run integrity-verified assembly and rely on both Windows CI architectures for relocation checks.
- [Updated bundle is incompatible] → Require the staged package contract and paired tests to pass before pushing the update.
