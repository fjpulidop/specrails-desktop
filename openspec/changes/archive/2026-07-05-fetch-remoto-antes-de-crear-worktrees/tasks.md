## 2. Remote-aware base-ref resolution (`server/integration-branch.ts`)

- [x] 2.1 [backend] Add `export async function resolveWorktreeBaseRef(git: GitRunner, input: { repoDir: string; integration: ResolvedIntegrationBranch; fetchOk: boolean }): Promise<{ baseRef: string; usedRemote: boolean; warning?: string }>`. Policy (see design.md Decision 1): if `input.integration.source === 'explicit'` → return `{ baseRef: input.integration.branch, usedRemote: false }` untouched, no git calls at all. Otherwise (`repo-default` / `project-setting` / `head-fallback`): if `!fetchOk` → `{ baseRef: input.integration.branch, usedRemote: false, warning: 'git fetch origin failed; using local ref' }`. If `fetchOk` → check remote-branch existence via `git.run(['rev-parse', '--verify', '--quiet', `refs/remotes/origin/${input.integration.branch}`], input.repoDir)`; `code === 0` → `{ baseRef: `origin/${input.integration.branch}`, usedRemote: true }`; non-zero (remote branch not found, e.g. an unpushed `project-setting` branch) → `{ baseRef: input.integration.branch, usedRemote: false, warning: `origin/${input.integration.branch} not found; using local ref` }`.
  - **Files:** Modify: server/integration-branch.ts
- [x] 2.2 [backend] Write unit tests in `server/integration-branch.test.ts`: (a) `source: 'repo-default'` + `fetchOk: true` + remote branch exists → `origin/<branch>`, `usedRemote: true`; (b) `source: 'project-setting'` + `fetchOk: true` + remote branch exists → same behavior; (c) `source: 'explicit'` + `fetchOk: true` → bare branch name returned, `usedRemote: false`, AND assert the `rev-parse --verify` git call was never made for this case (explicit must not even pay the existence-check cost); (d) `fetchOk: false` for a `repo-default` source → bare branch name, `usedRemote: false`, `warning` present; (e) `fetchOk: true` but `origin/<branch>` doesn't exist (e.g. a `project-setting` branch never pushed) → bare branch name, `usedRemote: false`, `warning` present; (f) `source: 'head-fallback'` behaves like `repo-default`/`project-setting` (not like `explicit`).
  - **Files:** Modify: server/integration-branch.test.ts
