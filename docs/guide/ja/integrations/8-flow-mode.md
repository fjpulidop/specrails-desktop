# Flow：まず作り、spec はあとで

Flow は、何を作りたいかまだはっきりしていないときに、エージェントと一緒に作るための方法です。ミッションでエージェントと会話すると、エージェントが分離された worktree で実際のコードを書いて実行します。結果に納得したら **これで決まり** を押します。レールが worktree を引き継ぎ、spec を導出して、いつもの検証・レビュー・デリバリーを実行します。

Implement はすでに説明できる作業を任せるためのもの、Flow はそれを見つけるためのものです。

## Flow の始まり方

Flow を名前で頼む必要はありません。探索的・視覚的なこと（「…を試してみたい」「どんな見た目がいいか分からない」）を伝えると、ミッションに 2 つの道を示すカードが表示されます。

- **Flow** — 今すぐ一緒に作り、spec は最後に作ります。
- **Spec + Implement** — まず spec を合意し、それからレールに任せます。

2 つの道は同じ重みで、常に同じ順番で表示されます。どちらもおすすめされることはなく、選ぶのはあなたです。**エージェントが尋ねた理由** には、エージェントが尋ねたきっかけが一文で示されます。どちらの道を選んでも、**今はしない** を押しても、エージェントがしつこく勧めることはありません。

Flow を選ぶと確認が表示されます。Specrails はエージェントがコードを書ける分離された worktree を作成し、メインブランチには触れません。**Flow を開始** を押してください。ボードに **Flow 中** ラベル付きの仮 spec が表示されます（クリックするとミッションに戻れます）。

お使いの Specrails Core がまだ Flow に対応していない場合、ボタンは無効になり、不足しているものがカードに表示されます。通常は Specrails Core を更新すれば解決します。

## Flow の最中

会話の見た目が変わり（縁に細いアクセントライン）、入力欄の上にバーが表示されます。

- worktree の **ブランチ**、追加・削除行数付きの **変更ファイル**、そしてこれまでの Flow の **実費**（プロバイダーの請求額）。コストが報告されたターンがあるまでは `—` と表示され、推定値は表示しません。
- **変更を表示** は、変更された各ファイルの状態と +/− を一覧表示します。
- **一時停止** はエージェントを止め、worktree と spec を保持します。ミッションには **Flow を再開** が表示されます。
- **破棄** は確認のうえ、worktree、そのブランチ、仮 spec を削除します。
- **これで決まり** — メインのアクションです（下記）。

エージェントが作業中でも入力できます。Flow ではメッセージが現在のステップに **割り込み**（送信ボタンが稲妻に変わります）、エージェントはすぐに新しい情報で作業を続けます。入力欄の下の git バーには worktree のブランチが表示されます。

## アプリを試す

Flow エージェントは自分で型チェックとテストを実行して作業を確認します。試せるものがあると、**Start the app**、**Start and expose on the local network**、**Not now** の 3 つの選択肢で尋ねます。公開すると同じ Wi-Fi や VPN のスマートフォンからアプリを開けますが、そのネットワーク上の誰でもアクセスできます。

アプリが待ち受けを始めると、エージェントがアドレスをリンクで示し、Flow バーに緑の点付きの **プレビュー** が表示されます。押すとブラウザでアプリが開きます。メニューにはネットワークアドレスと **アプリを停止** があります。アプリは Flow の worktree で動き、メインのチェックアウトでは動きません。Flow を一時停止・破棄・引き渡すと Specrails が停止します。

## これで決まり

結果に満足したら **これで決まり** を押します。Flow バーと視覚効果が消え、いつものレール起動カードが **Flow → Spec** ループを選択済み・空いているレールを選択済みの状態で表示されます。必要ならエンジン、モデル、エフォートを調整して **起動** を押してください。レビュー上限や予算に達している場合、カードはその旨を表示し、起動しません。**まだ** を押すと Flow に戻ります。

レールは作ったものから Specrails の spec と OpenSpec の change を導出し、検証とレビューを行います。デリバリーカードは通常の実行と同じようにミッションに表示されます。

## 知っておくと便利なこと

- Flow は自分の worktree の中にだけ書き込みます。Flow の外では、ミッションは読み取り専用のままです。
- 1 つのミッションで同時に開ける Flow は 1 つです。一時停止はアプリの再起動後も保持されます。
- worktree が消えた場合、Flow は **確認が必要** とマークされ、何も削除されません。
- Flow の最中や破棄したときに、Jira には何も送られません。
- Flow のコストは Analytics で独立したサーフェス **Flow** として、またエージェントミッションのブロック内に表示されます。
