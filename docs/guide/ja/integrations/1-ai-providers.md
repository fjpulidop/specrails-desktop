# AI プロバイダーを接続する {#ai-providers}

Specrails は、認証済みの Claude または Codex CLI を連携させて動かします。プロバイダーのインストール、アカウントへのアクセス、モデルの課金は、アプリとは別に管理されます。

## 接続して確認する

使いたい CLI を公式の手順に従ってインストールし、使用するアカウントでサインインします。Specrails で利用可能かどうかを確認し、ミッションまたはレールに対応するモデルと設定を選びます。

検出チェックが成功しても、次の呼び出しでクォータやネットワークが利用できることは保証されません。実装を再試行する前に、認証と互換性のエラーを解決してください。

## 境界を理解する

アプリはプロジェクトの記録をローカルに保存しますが、モデルへのリクエストや設定済みのインテグレーションは、コンテキストをマシンの外へ送信することがあります。それを踏まえて、どの参照や添付ファイルを渡すかを選んでください。

機能はプロバイダーごとに異なります。推論の制御、構造化レスポンス、サブエージェント、実行中ターンのステアリングは、プロバイダー間で置き換えがききません。[プロバイダーの実行設定](../pipeline/picking-an-engine-per-rail)と[ステアリング](../pipeline/the-job-detail-view)を参照してください。

Sonnet を選ぶと Claude Sonnet 5.5（`claude-sonnet-5-5`）が実行されます。[Anthropic](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)。
