# 最初のプロジェクトを追加する

プロジェクトとは、コードベースを収めたコンピュータ上のフォルダにすぎません。さっそく、ひとつ接続してみましょう。

## プロジェクト追加ダイアログを開く

ようこそ画面の**最初のプロジェクトを追加**をクリックします（後からは左サイドバーの**プロジェクトを追加**ボタンでも構いません）。小さなダイアログが表示されます。

## 詳細を入力する

**プロジェクトフォルダ** *（必須）*

コードが入っているフォルダを specrails に指定します。デスクトップアプリではフォルダアイコンをクリックして視覚的に選ぶか、フルパスを貼り付けられます。リポジトリのルート — コードと（通常は）`.git` ディレクトリを含むフォルダ — を指定してください。

**プロジェクト名** *（任意）*

サイドバーに表示される分かりやすいラベルです。空欄のままにすると、specrails はフォルダ名を使います。

> 必要なツールが揃っているか、バックグラウンドで簡単なチェックが実行されます。必須のものが欠けていると**追加**ボタンは無効のままになり、**詳細情報**リンクが正確なインストールコマンドを示します。

フォームはこれだけです — **追加**をクリックすれば完了です。

## AI プロバイダーは自動検出されます

もうプロバイダーを選ぶ必要はありません。specrails はマシンにインストールされたすべての AI CLI — **Claude**、**Codex**、**Gemini**、**Kimi** — を検出し、どのプロジェクトでも常にそのすべてを使えます。後から新しいプロバイダーをインストールすれば、次にアプリへ戻ったときに自動であらゆる場所に現れます。再セットアップも、プロジェクトごとの設定も不要です。インストール済みでも未ログインのプロバイダーには、セレクターに控えめな*未ログイン*バッジが表示されます。

## セットアップは静かに行われます

セットアップウィザードはありません。**追加**をクリックした瞬間にプロジェクトは登録され、サイドバーに現れます — すぐに開けます。バックグラウンドで specrails がプロジェクトの workspace を組み立てます（数秒、完全オフライン）。プロジェクト行の小さく点滅するドットが作業中を示し、すべて整うと自然に消えます。あるプロバイダーで失敗しても、プロジェクトは他のプロバイダーで動き続けます — 琥珀色のドットが現れ、クリックすると再試行します。

## 何が、どこにインストールされるのか

セットアップは意図的に**非侵襲的**です。あなたのリポジトリは手つかずのまま。specrails のすべての成果物（エージェント定義、コマンド、プロファイル、ローカル設定）はホームディレクトリ配下のプロジェクトごとの workspace に置かれ、アプリに同梱された単一の共有フレームワークにリンクされます。リポジトリが変更されることはありません — アプリの更新時には、すべてのプロジェクトが新しいフレームワークを自動で、一度に受け取ります。

> **より深いセットアップを望むなら？** アプリはあえて高速なテンプレートインストールを既定にしています。AI で強化されたフロー（コードベース分析とカスタムエージェントペルソナ）が良ければ、ターミナルでプロジェクトフォルダから `npx specrails-core@latest init` を実行できます。

## 準備完了

**追加**をクリックした瞬間からプロジェクトのダッシュボードが使えます。さあツアーへ — [ダッシュボードツアー](the-dashboard-tour)をご覧ください。
