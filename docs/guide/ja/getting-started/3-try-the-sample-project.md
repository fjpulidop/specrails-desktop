# サンプルプロジェクトを試す

自分のコードに specrails を向ける前に、スペックがレビュー済みの変更になる様子を見てみたいですか？**サンプルプロジェクト**は、3つの用意済みスペックが付いた小さな○×ゲームの Web アプリです。数分で終わり、本物の**レビューパケット**にたどり着きます。

## 始める

ウェルカム画面で**サンプルプロジェクトで試す**（**最初のプロジェクトを追加**の隣）をクリックします。何かが起きる前に、ダイアログが次を伝えます。

- **作成されるもの**：専用の git リポジトリに入った小さな Web ゲームと、ボードに並ぶ3つのスペック。
- **作成場所**：既定ではホームフォルダ内の `~/Specrails Samples/tic-tac-toe`。フォルダは変更できます。既存のフォルダが上書きされることはありません。
- **実行にかかる費用**：「≈ $0.30–$1 · 約 3–5 分」のような見積もり。プロバイダーが従量課金の場合にのみドルで表示されます。サブスクリプションプランでは追加料金なし、ローカルエンジンでは API 料金なしと表示されます。

サンプルの作成は無料で、何も実行しません。**サンプルプロジェクトを作成**をクリックすると、ボードに移動します。

## 3つのステップ

小さなガイドカードが、実際のボードを1ステップずつ指し示します。いつでも閉じることができ、**サンプルプロジェクト**のピルに折りたたまれます。**ガイドを表示**で元に戻せます。

1. **スペック。** 3つのスペックはあらかじめ書かれています。それぞれ、何を作るか、何をもって完了とするかが書かれています。
2. **レール。** **最初のスペックを実行**をクリックします。サンプルは低コストで上限付きに設定されています。クイックモード、利用可能な最も安いモデル、実行ごとのソフト上限（$1 を超える前に一時停止して確認）です。ローカルエンジンを設定している場合は、API 料金なしでそちらを選べます。
3. **レビュー。** 何も勝手にマージされません。実行が終わると、**レビューパケット**が変更内容を示し、承認か破棄を選べます。

## 使える AI プロバイダーがない場合

実行を提示する前に、specrails はプロバイダーがインストールされ、サインインしているかを確認します。準備できていない場合は、代わりに**録画された実行を見る**が表示されます。完了した実行をレビューパケットまで再生するものです。録画であることが明示され、何も実行されず、課金もされません。プロバイダーをインストールまたはサインインしてから**再確認**を選ぶと、実際の実行に切り替わります。

## そして、自分のプロジェクトへ

ガイドは**自分のプロジェクトを追加**で終わります。サンプルが不要になったら、**サンプルを削除**でワンクリックで登録解除できます。**サンプルのフォルダも削除する**にチェックを入れない限り、フォルダはディスクに残ります。この削除は元に戻せません。

## プラットフォームツアーをもう一度見る

ツアーはウェルカム画面から移動しました。**ドキュメント**を開いて**ツアーをもう一度見る**を選ぶか、コマンドパレットを開いて「ツアーをもう一度見る」と入力します。**設定 ▸ 外観**にもあります。
