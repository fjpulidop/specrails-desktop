# ユニバーサル検索（⌘K）

**⌘K**（Windows と Linux では **Ctrl+K**）を押すと、ミッション、スペック、ジョブログ、ファイル、設定、このガイドなど、Specrails のほぼすべてを 1 か所から検索できます。通常の検索語を入力すると、これまでどおりミッション、プロジェクト、スペック、最近のジョブを検索します。**プレフィックス**で始めると、1 つの対象だけを検索します。

## プレフィックス

| 入力 | 検索対象 | Enter で開くもの |
| --- | --- | --- |
| `#` | スペック：タイトル、概要、説明、ラベル、対象外メモ、追記、コメント。`#12` は 12 番のスペックを見つけます。 | そのスペック |
| `@` | ミッション：タイトルと会話の内容。 | そのミッション |
| `/` | 設定（Desktop とプロジェクト）。名前や呼び方で探せます。 | 該当ブロックにスクロールしてフォーカスした設定画面 |
| `f:` | プロジェクトのファイル（名前またはパス）。 | コードエクスプローラーでそのファイル |
| `log:` | ジョブログ：コマンド、ループ名、フェーズ名、失敗の診断。 | そのジョブ |
| `?` | このガイド：ページ名と見出し。 | ガイドのその見出し |

プレフィックスを入力すると検索ボックス内の**チップ**になり、ボックスには検索語だけが残ります。ボックスが空のときに **Backspace**（またはチップの × をクリック）で範囲を解除できます。ボックスが空のときは、パレットがボックスの下にプレフィックスを一覧表示します。クリックして開始できます。`>` は従来どおりアクションを一覧表示します。

## ハイライト

結果には最初の一致箇所の前後の短い抜粋が表示され、一致した部分が強調されます。検索では大文字小文字とアクセントを区別しないため、`revision` で「Révision」が見つかります。

## 設定

`/` は、テーマ、言語、エディタ、予算、通知、Webhook、アップデート、ブランチ、環境、テレメトリ、ルールなど、主要な設定ブロックをお使いの言語で把握しています。プロジェクト設定は、プロジェクトを開いているときに表示されます。選ぶと、該当ブロックで正しい画面が開きます。プレフィックスなしでも、強い一致（3 文字以上）があれば、通常の結果に設定が最大 3 件追加されます。

## ジョブログ

`log:` は、実行の生の出力ではなく、コンパクトなインデックスを検索します。コマンド、ループ名、フェーズ名、失敗・ブロック・停止した実行の短い診断が対象です。トークンストリームやツール出力は保存しないため、小さく高速なままです。プロジェクトごとに保持され、最新の実行を含みます。

## 知っておくと便利なこと

- `#`、`f:`、`log:` はアクティブなプロジェクトを検索します。先にプロジェクトを開いてください。
- ファイルの範囲は、コードエクスプローラーの除外ルールに従います。
- 各グループには上位の結果だけが表示されます。検索語を絞り込んでください。
