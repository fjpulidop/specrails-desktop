# Loop Builder

**レールは Loop を実行します。** 組み込みの Loop（`Implement`、`Batch`、`Freestyle`）は日常的なケースをカバーしますが、**Loop Builder** を使えば自分だけの Loop を設計できます — 目標が達成されるまで繰り返す自動化のための、n8n スタイルのビジュアルエディターです。このページでは、Loop とは何か、どう作るのか、そしてレールでどう実行するのかを説明します。

## Loop とレール — その関係

**Loop** は作業の *レシピ* で、**レール** はそれをあなたのスペックに対して実行する *レーン* です。

```
   Loop Builder（左サイドバー）             レール（右）
   ───────────────────────────             ─────────────
   Implement   （組み込み）                  レール 1
   Batch       （組み込み）      ► で選ぶ      Loop: Verify-until-green
   Freestyle   （組み込み）                    ▶ Play
   Verify-until-green （あなたの作ったもの）
```

- Loop は **Loops** セクション（左サイドバー、プロジェクトの隣）にあります — これらは **グローバル** で、すべてのプロジェクトで共有されます。
- レールはヘッダー（Loop ピッカー）で **Loop を選び**、Play を押すとそれを実行します。
- プロバイダー、モデル、推論の労力（reasoning effort）を決めるのは **レール** であって、Loop のステップではありません。同じ Loop が、レール次第で Claude、Codex、Gemini のいずれでも実行されます。

つまり、Loop を一度作ってしまえば、どのプロジェクトのどのレールでもそれを選べます。

## ビルダーを開く

左サイドバーの **Loops** をクリックすると、ライブラリが表示されます。3 つの組み込み Loop に加えて、あなた自身の Loop が並びます。どれかを開いて中身を見るか、**New loop** をクリックして真っ白なキャンバスから始めます。

組み込みの Loop を直接編集するのは簡単ではありません — 代わりに **Fork** します。そうすると、ちゃんと動くグラフの編集可能なコピーが手に入るので、そこから始められます。これが一番手っ取り早い学び方です。

## Loop を構成するもの

Loop は **ノード** を **エッジ**（矢印）でつないだグラフです。各ノードが 1 つのステップです。

| ノード | 役割 |
|------|--------------|
| **Start** | 実行が始まる場所。1 つの Loop につきちょうど 1 つ。 |
| **AI Step** | AI のターンを実行します — あなたが書くプロンプト、または `{{cmd:implement}}`、`{{cmd:verify}}`、`{{cmd:fix}}` のような *マジックコマンド*。ここで本物の作業が行われます。 |
| **Shell** | シェルコマンド（例: `npm test`）を実行し、その出力を後続のステップ用にキャプチャします。 |
| **Loop Decider** | Loop の頭脳。各パスで、あなたが書いた **目標（goal）** を読み、**continue**（ループバックしてもう一度試す）か **stop**（抜ける）かを判断します。*verify → fix → verify until green* を動かしているのがこれです。 |
| **End** | 終端ノード。実行を成功または失敗としてマークします。 |

エッジはステップを順番につなぎます。**Loop Decider** には **continue** と **stop** という 2 つのラベル付き出力があるので、「まだ終わっていない」を作業へ配線して戻し、「終わった」を End へ配線して出します。

### ステップのテキストを書く

AI Step や Decider の中では、次のものを参照できます。

- **スペックデータ** — `{{spec.title}}`、`{{spec.description}}`、`{{spec.ids}}`（レールのチケット ID）。実行時にレール上のスペックから埋め込まれます。
- **マジックコマンド** — `{{cmd:implement}}` とその仲間は、対応するパイプラインコマンドに展開されます。
- **定数（Constants）** — `{{const:NAME}}` はグローバルな **定数ライブラリ** から値を引き込みます（パレットからドラッグして追加します）。検証の PASS/FAIL マーカーのような組み込みのセンチネルは常に利用できます。自分で追加して、すべての Loop で再利用することもできます。

## Loop を有界に保つ

止まらない Loop はお金を永遠に燃やし続けてしまうので、すべての実行に 3 つのガードがあります（ビルダーのツールバーで設定します）。

| ガード | 役割 |
|-------|--------------|
| **Max iterations** | Decider が判断にかかわらずループバックできる回数のハードキャップ。 |
| **Timeout (min)** | 実行全体に対する実時間（壁時計）の上限。 |
| **Max cost ($)** | *任意。* 累積コストが予算を超えた時点で Loop を停止します。**ステップとステップの間** でチェックされるため（あるステップのコストはそれが終わってからしかわかりません）、1 ステップ分だけオーバーシュートすることがあります。Claude ではコストは正確で、Codex と Gemini では見積もりです。上限を設けないなら空のままにしておきます。 |

## 自信を持って組み立てる

ビルダーは、Loop が実行される前に正しく仕上げる手助けをしてくれます。

- **ライブバリデーション** — 問題（Start がない、孤立したステップ、空のプロンプト、ブランチの欠けた Decider など）がキャンバス上と問題パネルにフラグ表示されます。
- **ドライランプレビュー** — **何も起動せずに** 各ステップの正確なテキスト（スペックデータ、定数、コマンドがすべて展開された状態）を解決するので、各ステップが何を送ることになるのかを正確に確認できます。
- **自動整列（Auto-arrange）** — キャンバスを縦・横・グリッドのいずれかにすっきり並べます。選択は Loop ごとに保存されます。
- **コピー / ペースト** — `Cmd/Ctrl + C` / `V` で、Loop の内部や Loop をまたいでステップをコピーします。
- **インポート / エクスポート** — Loop を `.json` ファイルに保存し、また読み込めます（名前が重複するものはスキップされ、残りはインポートされます）。
- **ステップの名前変更** — 各ノードにカスタムラベルを付けて、グラフが読みやすくなるようにします。

## 公開して実行する

Loop は最初は **Draft** です。グラフが有効になったら **Publish** します — 公開された Loop が、レールの Loop ピッカーに表示されるものです。（削除せずに流通から外したいときは Unpublish します。）

カスタム Loop を実行するには、

1. プロジェクトを開いて、スペックをレールにドラッグします。
2. レールヘッダーで **Loop ピッカー** を開き、公開したあなたの Loop を選びます。
3. **▶ Play** を押します。

実行は **ジョブ** ビューで、他のレールジョブと同じメトリクスとコストトラッキングとともにライブでストリーミングされます — さらにそのログには専用の**ステップエクスプローラー**が付きます。グラフのライブマップの下にステップごとの折りたたみボックスが並び、Loop が進むにつれて実行中のステップを追従します（[ジョブ詳細ビュー](the-job-detail-view) を参照）。Claude では各 **AI ステップ**もライブセッションです。ジョブ詳細のコンポーザーからメッセージを送ってステップの途中で舵取りできます（ステップの合間はコンポーザーが少し待機し、**このステップを確定**すればその成果とともに Loop が先へ進みます）。反復回数やコストの上限に達して停止した Loop は、ただの成功ではなく、その結果とともに報告されます。

> **Loop の実行中の注意点。** いずれかの実行が動いている間は、その Loop を編集したり削除したりできません — 先に実行を止めてください。
