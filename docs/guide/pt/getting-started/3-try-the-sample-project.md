# Experimentar o projeto de exemplo

Queres ver uma spec tornar-se uma alteração revista antes de apontar o specrails ao teu próprio código? O **projeto de exemplo** é um pequeno jogo web do galo com três specs já escritas. Demora alguns minutos e termina num **pacote de revisão** real.

## Começar

No ecrã de boas-vindas, clica em **Experimente num projeto de exemplo** (ao lado de **Adicionar o teu primeiro projeto**). O diálogo diz-te, antes de acontecer qualquer coisa:

- **O que é criado**: um pequeno jogo web no seu próprio repositório git, com três specs já no teu quadro.
- **Onde**: por defeito `~/Specrails Samples/tic-tac-toe`, dentro da tua pasta pessoal. Podes mudar a pasta; uma pasta existente nunca é substituída.
- **Quanto custaria uma execução**: uma estimativa como «≈ $0,30–$1 · cerca de 3–5 min». Só aparece em dólares quando o teu fornecedor fatura por utilização. Com um plano de subscrição indica que não há custo extra, e com um motor local não há custo de API.

Criar o exemplo não custa nada e não executa nada. Clica em **Criar projeto de exemplo** e chegas ao Quadro.

## Os três passos

Um pequeno cartão guia aponta para o Quadro real, passo a passo. Podes fechá-lo a qualquer momento; reduz-se a uma pílula **Projeto de exemplo** de onde **Mostrar guia** o traz de volta.

1. **A spec.** As três specs foram escritas para ti. Cada uma diz o que construir e como saber que está concluída.
2. **O rail.** Clica em **Executar a primeira spec**. O exemplo está preparado para ser barato e limitado: modo rápido, o modelo mais barato disponível e um limite suave por execução (a execução pára e pergunta antes de ultrapassar $1). Se tiveres um motor local configurado, podes escolhê-lo, sem custo de API.
3. **A revisão.** Nada é integrado sozinho. Quando a execução termina, um **pacote de revisão** mostra o que mudou e deixa-te aceitar ou descartar.

## Nenhum fornecedor de IA pronto?

Antes de te oferecer a execução, o specrails verifica se há um fornecedor instalado e com sessão iniciada. Se não houver, vês **Ver uma execução gravada**: a repetição de uma execução concluída que termina num pacote de revisão. Está claramente identificada como gravação; nada corre e nada é cobrado. Instala um fornecedor ou inicia sessão e escolhe **Verificar novamente** para passar a uma execução real.

## Depois, o teu próprio projeto

O guia termina com **Agora adiciona o teu próprio projeto**. Quando terminares com o exemplo, **Remover exemplo** remove-o com um clique. A pasta fica no disco, a menos que marques **Eliminar também a pasta do exemplo**, o que não pode ser desfeito.
