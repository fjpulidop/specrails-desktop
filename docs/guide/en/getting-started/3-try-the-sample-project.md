# Try the sample project

Want to see a spec become a reviewed change before you point specrails at your own code? The **sample project** is a tiny tic-tac-toe web game with three ready-made specs. It takes a few minutes and ends at a real **Review packet**.

## Start it

On the welcome screen, click **Try it on a sample project** (next to **Add your first project**). The dialog tells you, before anything happens:

- **What is created**: a small web game in its own git repository, with three specs already on your board.
- **Where**: by default `~/Specrails Samples/tic-tac-toe` inside your home folder. You can change the folder; an existing folder is never overwritten.
- **What a run would cost**: an estimate such as "≈ $0.30–$1 · about 3–5 min". It is only shown as dollars when your provider bills per use. On a subscription plan it says there is no extra charge, and on a local engine there is no API cost.

Creating the sample costs nothing and runs nothing. Click **Create sample project** and you land on the Board.

## The three steps

A small guide card points at the real Board, one step at a time. You can dismiss it at any moment; it collapses to a **Sample project** pill where **Show guide** brings it back.

1. **The spec.** The three specs are written for you. Each says what to build and how to know it is done.
2. **The rail.** Click **Run the first spec**. The sample is set up to be cheap and bounded: Quick mode, the cheapest available model, and a per-run soft cap (the run pauses and asks before passing $1). If you have a local engine configured you can choose it instead, with no API cost.
3. **The review.** Nothing is merged on its own. When the run ends, a **Review packet** shows what changed and lets you accept or discard it.

## No AI provider ready?

Before offering the run, specrails checks that a provider is installed and signed in. If none is ready you get **Watch a recorded run** instead: a replay of a finished run that ends at a Review packet. It is clearly labelled a recording; nothing runs and nothing is charged. Install or sign in to a provider, then choose **Check again** to switch to a real run.

## Then, your own project

The guide ends with **Now add your own project**. When you are done with the sample, **Remove sample** unregisters it with one click. The folder stays on disk unless you tick **Also delete the sample folder**, which cannot be undone.
