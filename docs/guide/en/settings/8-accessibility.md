# Accessibility and personalisation {#accessibility}

Specrails adapts to how you work. Everything here lives in **Settings ▸ Appearance** and applies at once; it is saved on this computer.

## Density {#density}

**Comfortable** keeps cards and rows roomy. **Compact** fits more on screen: the specs board starts as compact rows, the jobs list uses tighter rows and the job story tightens its timeline. A saved board view keeps its own layout, so a view that was saved as post-it cards still opens as post-it cards.

## Reduce motion {#reduce-motion}

**Follow system** respects your operating system. **Reduce** turns animations and transitions off inside Specrails whatever the system says: the rail pill rests at its position, live dots stop pulsing and the Builder halo and the theme effects stay still. **Full motion** animates even when the system asks for less.

## Move a spec from the keyboard {#keyboard-moves}

Focus a spec card on the board (Tab or the arrow keys) and press **M**. A small picker lists the statuses and the rails; choose one with the arrow keys and **Enter**. It does the same as dragging the card there, including Jira-backed specs, which move through your Jira workflow. If the card is part of a multi-selection (**X** selects the focused card), the move applies to every selected spec. The command palette offers the same thing as **Move focused spec…**. **M** does nothing while you are typing in a field.

## Run updates for screen readers {#live-status}

Specrails announces run changes through a polite live region, for the project you are looking at: a run started, paused, needs you, failed, finished or has a review ready. Bursts are merged and repeats are dropped, so a busy rail never floods the reader. Undo toasts already announce themselves.

## Keyboard focus {#focus}

Every button, link, menu item, card and tree row shows a visible focus ring when you reach it with the keyboard. Information that used to live only in a tooltip, such as a spec reference on a rail strip, is also available to keyboard and screen reader users.
