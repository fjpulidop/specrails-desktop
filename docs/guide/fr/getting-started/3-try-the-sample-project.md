# Essayer le projet exemple

Vous voulez voir une spec devenir un changement relu avant de pointer specrails vers votre propre code ? Le **projet exemple** est un petit jeu web de morpion avec trois specs toutes prêtes. Il faut quelques minutes et on arrive à un vrai **paquet de revue**.

## Le lancer

Sur l'écran d'accueil, cliquez sur **Essayer sur un projet exemple** (à côté de **Ajouter votre premier projet**). La boîte de dialogue vous dit, avant tout :

- **Ce qui est créé** : un petit jeu web dans son propre dépôt git, avec trois specs déjà sur votre tableau.
- **Où** : par défaut `~/Specrails Samples/tic-tac-toe`, dans votre dossier personnel. Vous pouvez changer le dossier ; un dossier existant n'est jamais écrasé.
- **Ce qu'une exécution coûterait** : une estimation du type « ≈ 0,30–1 $ · environ 3–5 min ». Elle n'est donnée en dollars que si votre fournisseur facture à l'usage. Avec un abonnement, elle indique qu'il n'y a pas de frais supplémentaires, et avec un moteur local il n'y a aucun coût d'API.

Créer l'exemple ne coûte rien et n'exécute rien. Cliquez sur **Créer le projet exemple** et vous arrivez sur le Tableau.

## Les trois étapes

Une petite carte de guidage montre le vrai Tableau, étape par étape. Vous pouvez la fermer à tout moment ; elle se réduit à une pastille **Projet exemple** d'où **Afficher le guide** la ramène.

1. **La spec.** Les trois specs sont écrites pour vous. Chacune dit quoi construire et comment savoir que c'est terminé.
2. **Le rail.** Cliquez sur **Exécuter la première spec**. L'exemple est réglé pour être économique et borné : mode rapide, le modèle le moins cher disponible et un plafond souple par exécution (elle s'arrête et demande avant de dépasser 1 $). Si un moteur local est configuré, vous pouvez le choisir, sans coût d'API.
3. **La revue.** Rien n'est fusionné tout seul. À la fin de l'exécution, un **paquet de revue** montre ce qui a changé et vous laisse l'accepter ou l'écarter.

## Aucun fournisseur d'IA prêt ?

Avant de proposer l'exécution, specrails vérifie qu'un fournisseur est installé et connecté. Si aucun ne l'est, vous obtenez **Voir une exécution enregistrée** : le rejeu d'une exécution terminée qui s'achève sur un paquet de revue. C'est clairement présenté comme un enregistrement ; rien ne s'exécute et rien n'est facturé. Installez un fournisseur ou connectez-vous, puis choisissez **Vérifier à nouveau** pour passer à une vraie exécution.

## Ensuite, votre propre projet

Le guide se termine par **Ajouter maintenant votre projet**. Quand vous en avez fini avec l'exemple, **Supprimer l'exemple** le retire en un clic. Le dossier reste sur le disque, sauf si vous cochez **Supprimer aussi le dossier de l'exemple**, ce qui est irréversible.

## Revoir la visite de la plateforme

La visite n'est plus sur l'écran d'accueil. Ouvrez **Docs** et choisissez **Revoir la visite**, ou ouvrez la palette de commandes et tapez « Revoir la visite ». Elle est aussi dans **Réglages ▸ Apparence**.
