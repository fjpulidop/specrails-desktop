# 用对话操作 Specrails（Agent Chat）

**Agent Chat** 是一个住在 Specrails *内部*的副驾驶，可以替你驱动整个应用。你不必再在项目、规格、轨道和分析之间来回点击，只需开口就行：*「这周有多少任务成功了？」*、*「在 API 项目里为社交登录创建一份规格」*、*「启动优先级最高的三个工单，完成后告诉我」*。它通过调用 Specrails 自己的工具来完成工作——正是 [MCP 服务器](./5-mcp-server.md)所暴露的那些工具——与此同时你能看到后面的仪表盘实时更新。

> **不要与流水线智能体混淆。** *智能体*板块（Architect → Developer → Reviewer）讲的是*轨道如何实现一份规格*。而 **Agent Chat** 是一个*操作应用本身*的单一助手。两回事，同一个词。

## 如何打开

窗口底部有一个漂浮的**气泡**——点击它即可打开面板，或在任何地方按 **⌘⇧A**（Windows/Linux 上为 **Ctrl+Shift+A**）。面板是一个真正的窗口，你可以移动、缩放、最大化，也可以把它收回气泡；它会记住你上次放的位置。

它**特意设计为非模态**：后面的仪表盘保持鲜活，所以当智能体启动一条轨道或创建一份规格时，你能实时看到它出现——你面对的不是一块冻结的屏幕。

## 前提条件：MCP 服务器

Agent Chat 通过内嵌的 **Specrails MCP 服务器**来驱动应用，因此它必须处于开启状态。如果没有开启，面板会打开并显示一个一键式的**启用 Specrails MCP** 横幅——按一下即可就绪（无需重启）。详情见[从任意 AI 控制 Specrails](./5-mcp-server.md)；不安装任何东西，一切都在你本机本地运行。

## 选择它作用的对象

标题栏有一个**项目选择器**（就像 Cursor 的那样）。选定一个项目，你提出的一切都会限定在它之内——*「启动高优先级的那些」*会针对那个项目来解析。把它留在**首页**，智能体就在你的整套配置上工作：它可以列出或创建项目，并回答涵盖全局的问题。如果你在首页却问了某个项目专属的事情，它会反问你是哪个项目（或主动提议创建一个），而不是瞎猜。

在这里选择项目**不会**移动你的仪表盘——智能体的目标和你正在看的内容是彼此独立的。

## 提供方与模型

在消息框正上方，你可以选择**提供方**（Claude、Codex 或 Gemini）及其**模型**。每个提供方都有各自的模型清单，切换提供方会以该提供方的默认模型开启一段全新会话——因此你可以，比如说，用 Claude 驱动应用，再切到 Codex 进行另一段对话，两者互不串扰。

## 权限级别——缰绳在你手里

智能体可以触及整个应用，因此由你来决定给它多大的自由，方法是按 **Shift+Tab** 实时切换的一个**级别**（与 Claude Code 使用的是同一套循环）。每个级别都包含其下方的一切：

| 级别 | 它能做什么 |
|---|---|
| 👀 **观察** | 只读——列出并查看项目、规格、任务、分析。什么都不会改变。 |
| ✍️ **编辑** | 以上 **+** 创建和编辑（规格、设置、轨道配置）——可撤销的改动。 |
| ⚡ **操作** | 以上 **+** 启动**会产生费用**的 AI 工作（轨道、规格生成）。 |
| 🔥 **自主** | 以上 **+** 删除和停止各种东西——不可逆的操作。 |

从**观察**开始，只有当你想让智能体动手时才提升级别。如果它尝试超出当前级别的操作，它会停下来，并准确告诉你需要切换到哪个级别——它绝不会绕过限制。这与 设置 ▸ MCP 的分级是相互独立的，后者管辖的是*外部*助手；这里的级别只针对这个应用内的智能体。

## 一些可以让它做的事

进入**操作**后，试试：

> *「列出 API 项目里所有待办规格，然后把优先级最高的三个分别放到独立的轨道上启动并盯着它们。」*
>
> *「我这周花了多少钱，按项目拆分一下？」*
>
> *「在 web 项目里为深色模式开关创建一份规格，带上 Contract Layer。」*
>
> *「上一批里有东西失败了——找出失败的任务并总结原因。」*

回复会顺滑地流式呈现，并已排版落地（标题、表格、列表），每一段都带一个小小的**复制**按钮。底部的状态标签会显示智能体此刻正在做什么——*思考中……*、*MCP · jobs*、*Terminal*——让你随时了解它的状态。

## 贴心细节

- **提示词历史。** 在输入框为空时，按 **↑**/**↓** 浏览你之前问过的内容（滚动时以淡化样式显示）；开始输入即可编辑，或按回车发送。
- **最小化，而不丢失。** 点击 ✕ 把面板收回气泡——对话仍在继续运行。重新打开时你会落在最新一条消息上；无需重新输入任何内容。
- **新建对话。** **+** 按钮开启一段全新的线程；历史记录存在于整个应用层面，凌驾于任何单个项目之上。

## 一些需要知道的事

- **操作和自主会产生费用**，因为它们运行 AI。智能体会在执行会产生费用的操作前把它们摆到明面上；如果你只想查看和整理，就把级别保持在观察或编辑。
- **智能体是全应用范围的**，并不绑定于你当前打开的项目——这正是它拥有自己的选择器、且历史记录不按项目区分的原因。
- **它的能力上限取决于 MCP 允许的范围。** 如果整个区域看起来都被禁用，请检查 MCP 服务器是否已启用。
