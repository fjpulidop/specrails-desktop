# 试用示例项目

想在把 specrails 指向你自己的代码之前，先看看一份规格如何变成经过审阅的变更吗？**示例项目**是一个小型井字棋网页游戏，附带三份现成的规格。只需几分钟，最终得到一个真实的**审阅包**。

## 开始

在欢迎页点击**在示例项目上试一试**（位于**添加你的第一个项目**旁边）。在任何事情发生之前，对话框会告诉你：

- **会创建什么**：一个带独立 git 仓库的小型网页游戏，看板上已有三份规格。
- **创建在哪里**：默认为主目录内的 `~/Specrails Samples/tic-tac-toe`。你可以更改文件夹；已存在的文件夹绝不会被覆盖。
- **一次运行的费用**：类似“≈ $0.30–$1 · 约 3–5 分钟”的估算。只有当你的提供商按用量计费时才以美元显示；订阅套餐会注明没有额外费用，本地引擎则没有 API 费用。

创建示例不花钱，也不运行任何内容。点击**创建示例项目**，即可进入看板。

## 三个步骤

一张小小的向导卡片会逐步指向真实的看板。你可以随时关闭它；它会收起为**示例项目**小标签，点击**显示向导**即可恢复。

1. **规格。** 这三份规格已为你写好。每份都说明了要构建什么，以及如何判断完成。
2. **轨道。** 点击**运行第一份规格**。示例已设置为低成本且有上限：快速模式、可用的最便宜模型，以及每次运行的软上限（运行会在超过 $1 之前暂停并询问）。如果你配置了本地引擎，也可以选择它，无需 API 费用。
3. **审阅。** 没有任何内容会自动合并。运行结束后，**审阅包**会展示改动内容，并让你接受或丢弃。

## 没有可用的 AI 提供商？

在提供运行之前，specrails 会检查是否已安装并登录了提供商。如果没有，你会看到**观看录制的运行**：回放一次已完成的运行，终点是一个审阅包。它被明确标注为录制内容；不会运行任何东西，也不会收费。安装提供商或登录后，选择**重新检查**即可切换到真实运行。

## 然后，你自己的项目

向导以**现在添加你自己的项目**收尾。用完示例后，点击**移除示例**即可一键注销。除非你勾选**同时删除示例文件夹**（此操作无法撤销），否则文件夹仍保留在磁盘上。

## 重新播放平台导览

导览已不在欢迎页。打开**文档**并选择**重新播放导览**，或打开命令面板并输入“重新播放导览”。它也在**设置 ▸ 外观**中。
