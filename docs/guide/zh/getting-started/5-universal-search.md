# 通用搜索（⌘K）

按 **⌘K**（Windows 和 Linux 上为 **Ctrl+K**），即可在同一处搜索 Specrails 中几乎所有内容：任务、Spec、作业日志、文件、设置和本指南。输入普通查询会像以前一样搜索任务、项目、Spec 和最近的作业；以**前缀**开头则只搜索某一类来源。

## 前缀

| 输入 | 搜索范围 | 按回车打开 |
| --- | --- | --- |
| `#` | Spec：标题、摘要、描述、标签、范围外说明、补充说明和评论。`#12` 可找到 12 号 Spec。 | 该 Spec |
| `@` | 任务：标题和对话内容。 | 该任务 |
| `/` | 设置（Desktop 和项目），可按名称或常用说法查找。 | 打开设置窗口并滚动、聚焦到对应区块 |
| `f:` | 项目文件，按名称或路径。 | 在代码浏览器中打开该文件 |
| `log:` | 作业日志：命令、循环名称、阶段标题和失败诊断。 | 该作业 |
| `?` | 本指南：页面标题和小节标题。 | 指南中对应的小节 |

输入前缀后，它会变成搜索框中的一个**标签**，输入框只保留你的查询。在输入框为空时按**退格键**（或点击标签上的 ×）即可取消范围。输入框为空时，面板会在其下方列出各个前缀，点击即可开始。`>` 仍然用于列出操作。

## 高亮

结果会显示首个匹配处周围的一小段文字，并高亮匹配内容。搜索忽略大小写和重音符号，因此 `revision` 可以找到 “Révision”。

## 设置

`/` 了解主要的设置区块，并使用你的语言：主题、语言、编辑器、预算、通知、Webhook、更新、分支、环境、遥测、规则等。打开项目后才会提供项目设置。选中一项，即可在对应区块打开正确的窗口。不带前缀时，强匹配（三个或更多字符）最多会向常规结果中添加三项设置。`/budget` 还能找到预算面板（上限、预测、假设分析），每周和每月的上限就在那里。像 `/implement` 这样的斜杠命令会单独成组列在设置下方，因此 `/` 前缀不会把它藏起来。

## 作业日志

`log:` 搜索的是一个精简索引，而不是运行的原始输出：命令、循环名称、阶段标题，以及失败、被阻塞或停滞的运行的简短诊断。它从不保存令牌流或工具输出，因此体积小、速度快。索引按项目保存，包含最近的运行。

## 须知

- `#`、`f:` 和 `log:` 搜索当前项目；请先打开一个项目。
- 文件范围遵循代码浏览器的排除规则。
- 每个分组只显示最佳的几条结果；可细化查询来缩小范围。
