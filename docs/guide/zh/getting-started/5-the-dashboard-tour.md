# 仪表盘导览

项目添加好了，现在你看到的就是你的**项目仪表盘**——把 spec 变成已交付代码的大本营。下面带你认认路。

## 整体格局

窗口分为三个区域：

- **左侧边栏**——你的项目列表。点击任意项目即可瞬间切换，窗口里其余的一切都会随之更新。**添加项目** 按钮也在这里。
- **主区域**——当前项目的仪表盘：你的 spec，以及运行它们的流水线。
- **右侧边栏**——在当前项目的各个区块之间导航。

## 主仪表盘

工作就在这里发生。仪表盘会展示：

- **你的 spec**——你创建的工单，按状态组织（从 Backlog/待办 一直到 完成）。你可以用列表、网格或便利贴卡片的形式查看，随你喜欢。
- **添加 spec 的入口**——开始一件新工作。你可以直接写一份快速 spec，也可以打开一个引导式的 **Explore** 对话，它会通过聊天帮你打磨想法，并替你拟好工单草稿。
- **Rails**——这些是 spec 被构建的泳道。把一个 spec 拖到某条 rail 上并启动它，就会让它走过“架构师 → 开发者 → 评审员 → 交付”这条流水线。多条 rail 可以同时运行，所以你能并行处理好几件事。

当一个 spec 正在运行时，你会看到它的流水线进度和实时日志——AI 在设计、编码、评审你的改动时的实时输出。

## 右侧边栏：项目区块

右侧边栏是你切换当前项目各部分的总开关。把鼠标悬停上去即可展开，也可以固定常开。你会看到这些区块：

- **仪表盘**——spec 看板和 rails（你刚才待的地方）。
- **任务**——这个项目的每一次流水线运行，无论过去还是当下，都带有状态、耗时，并能深入查看任意一次运行的详情和日志。
- **集成**——可选的附加组件，比如把你的 spec 连接到 **Jira** 看板，或为 AI 启用额外的工具。
- **设置**——项目级选项（遥测、预算、提供商配置等等）。

## 状态栏

窗口最底部有一条细长的横条。它虽小，却很顺手：

- **连接指示灯**（左侧）——一个彩色圆点加标签，表明应用处于在线状态：绿色代表*已连接*，琥珀色代表*重新连接中*，蓝色代表刚重连后正在*同步中*。你很少会用到它，但需要时它能让人安心。
- **总花费**（右侧）——你已花金额的实时累计，让成本始终一眼可见。
- **终端开关**（最右侧）——打开内置的终端面板。随时按 **Cmd+J**（macOS）或 **Ctrl+J**（Windows/Linux）即可切换。它是一个完整的 shell，直接在你的项目文件夹里打开。

## 几个顺手的快捷键 {#shortcuts}

- **Cmd/Ctrl+B**——固定或收起左侧边栏；**Option+Cmd+B**（**Ctrl+Alt+B**）对右侧边栏执行相同操作。
- **Cmd/Ctrl+J**——切换终端面板。
- **Cmd/Ctrl+K**——命令面板：搜索任务、项目和 job，并**执行操作**。输入动词（如“新建”“启动”“移动”“切换”）或以 **>** 开头即可列出操作：新建 Spec（也可用探索模式）、启动或移动 Spec、打开其评审、交接或暂停 Flow、新建任务、切换主题、在任务模式与看板模式之间切换、在指定分区打开应用或项目设置、运行 Loop、切换侧边栏、后退或前进、撤销上一次更改，以及最近删除。需要选择的操作（Rail、状态、主题、分区）会打开第二页；搜索框为空时按 **Backspace** 返回。每个操作都会显示它的快捷键，面板因此也在教你按键。它只提供当前位置可用的操作，并遵守与按钮相同的规则（无法启动的 Spec 不会出现）。搜索为空时会列出你的**最近操作**和**最近位置**。
- **Cmd+[ / Cmd+]**（Windows/Linux 为 **Alt+← / Alt+→**）、标题栏中的 **←  →** 按钮，或鼠标的后退/前进键——在你去过的位置之间后退或前进：规格、任务、作业、项目和全屏面板。右键（或长按）按钮可查看最近的位置。
- **Cmd+Shift+I**（Windows 和 Linux 上为 **Ctrl+Alt+I**）或标题栏中的**待处理**按钮 —— **待处理**列表：把所有项目中等你处理的事项集中在一个按项目分组的列表里。它汇集了可以决定的评审、代理正在等待的提问、失败或被阻塞的运行、因每日预算而暂停的运行，以及未能同步的 Jira 更新。每一行都带有主要操作（**打开评审**、**回答**、**继续**、**重试**），以及**稍后提醒**（1 小时或明天）和**完成**。被推迟或已完成的事项一旦状态变化会自动回来。按钮会显示有多少项在等待，服务商额度提示通知也会打开该列表。该列表还是一个链接（`?inbox=1`），并且是命令面板中的一个操作。
- **M** — 在看板上聚焦某张规格卡片时,打开选择器把它移到某个状态或某条 Rail,相当于拖放的键盘版本。多选同样适用,命令面板中对应的是**移动聚焦的规格…**。
- **?** — 快捷键速查表。在它的搜索框里输入内容，可以筛选快捷键，并找到本指南中匹配的页面和章节，它们会直接在指南中打开，无需离开当前界面。设置、轨道、Flow、上下文滑块和预算旁边的小 **ⓘ** 图标和**了解更多**链接，也会以同样方式打开指南的对应章节。

## 下一步去哪儿

地形就摸到这儿。从这里出发，最自然的第一步是**添加一个 spec** 并在某条 rail 上启动它——看着流水线从头跑到尾，然后去 **分析** 里看看花了多少钱。欢迎上路。
