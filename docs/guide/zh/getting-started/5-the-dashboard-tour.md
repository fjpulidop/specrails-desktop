# 仪表盘导览

项目添加好了，现在你看到的就是你的**项目仪表盘**——把 spec 变成已交付代码的大本营。下面带你认认路。

## 整体格局

窗口分为三个区域：

- **左侧边栏**——你的项目列表。点击任意项目即可瞬间切换，窗口里其余的一切都会随之更新。**添加项目** 按钮也在这里。
- **主区域**——当前项目的仪表盘：你的 spec，以及运行它们的流水线。
- **右侧边栏**——在当前项目的各个区块之间导航。

## 主仪表盘

工作就在这里发生。仪表盘会展示：

- **你的 spec**——你创建的 spec，按状态组织（从 Backlog/待办 一直到 完成）。你可以用列表、网格或便利贴卡片的形式查看，随你喜欢。
- **添加 spec 的入口**——开始一件新工作。你可以直接写一份快速 spec，也可以打开一个引导式的 **Explore** 对话，它会通过聊天帮你打磨想法，并替你拟好 spec 草稿。
- **Rails**——这些是 spec 被构建的泳道。把一个 spec 拖到某条 rail 上并启动它，就会让它走过“架构师 → 开发者 → 评审员 → 交付”这条流水线。多条 rail 可以同时运行，所以你能并行处理好几件事。

当一个 spec 正在运行时，你会看到它的流水线进度和实时日志——AI 在设计、编码、评审你的改动时的实时输出。

## 右侧边栏：项目区块

右侧边栏是你切换当前项目各部分的总开关。把鼠标悬停上去即可展开，也可以固定常开。你会看到这些区块：

- **仪表盘**——spec 看板和 rails（你刚才待的地方）。
- **任务**——这个项目的每一次流水线运行，无论过去还是当下，都带有状态、耗时，并能深入查看任意一次运行的详情和日志。
- **集成**——可选的附加组件，比如把你的 spec 连接到 **Jira** 看板，或为 AI 启用额外的工具。
- **设置**——项目级选项（遥测、预算、提供商配置等等）。

## 状态栏

窗口最底部有一条细长的横条。它在任务模式和看板模式下看起来一样，而且很安静：没什么要说时，那个位置就是空的。

- **连接**（左侧）——一切正常时为空。只有当应用与本地服务器失去连接时，才会显示*重新连接中…*（琥珀色）或*离线*（红色），重连后会短暂显示*同步中…*。
- **更新**（右侧）——有新版本就绪且应用空闲约半分钟后出现。点击它打开更新卡片（参见[更新](../settings/6-updates.md)）。
- **套餐用量**（右侧）——为最接近限额的提供商显示一个指示。80% 之前保持中性色，从 80% 起变为琥珀色并显示提供商名称，从 90% 起变为红色；提供商拒绝请求时显示 *限额 · 15:00 重置*。悬停或点击它可查看每个提供商的窗口以及本项目今天的花费。
- **应用资源**（右侧）——仅在有工作运行时显示一个图标和进程数。点击它可查看 CPU 和内存、内存趋势以及按来源的划分：任务和聊天、轨道、循环和作业、后台进程、终端、代理 CLI、MCP 和运行器、Git，以及 Specrails 服务器本身。展开某个来源即可查看它的进程。在各来源下方，**运行 worktree 的端口**列出每个 rail 的开发或测试服务器正在使用的端口（rail、规格、项目和进程），并在其他进程占用 rail 分配的端口时发出警告。在桌面应用中，**保持电脑唤醒** 也在这里；开启期间，状态栏中会有一个杯子图标提示（点击它即可重新允许睡眠）。
- **终端开关**（最右侧）——打开内置的终端面板。随时按 **Cmd+J**（macOS）或 **Ctrl+J**（Windows/Linux）即可切换。它是一个完整的 shell，直接在你的项目文件夹里打开。

## 独立的窗口

在桌面应用中，有些界面会以真正的窗口打开，而不是主窗口里的面板：**设置**、从任务中打开的 job 详情，以及任务模式下的 **Loops** 和 **插件**。你可以把它们移到另一块屏幕上，同时继续在主窗口里工作。每个窗口都使用系统自带的窗口控件；设置窗口和 job 窗口也可以按 **Escape** 关闭。你在其中做的更改（例如主题或语言）会立即应用到主窗口。在浏览器版本中，这些界面会以面板形式打开。

## 需要你处理的事的通知 {#attention}

当有事需要你时，Specrails 会告诉你：提问或任务的回复、等你决定的评审、失败、被阻塞或停止推进的运行、支出上限，以及完成的作业。方式取决于你在哪里：

- **不在应用中** —— 一条写明项目和原因的系统通知。在桌面应用中它无法点击，所以你回来时会有一条提示汇总（**有 3 项在等你**），并打开该项；有多项时打开 **待处理**。在 **从中断处继续** 或平台导览打开期间到达的提示会等到你关闭它，然后合并为一条送达。
- **在应用的其他位置** —— 一条带 **打开** 的小提示。
- **你已经在看** —— 不打扰。你正在看的任务不会通知它自己的回复；卡住的运行是例外，总会提醒。

收件箱中每一项的新状态只通知一次；重启后不会再次通知旧的内容。在收件箱中，你还没看过的项带有一个圆点；**标为未读** 和 **标为已读** 可以切换。在桌面应用中，程序坞图标（Linux 上为启动器）会显示你还没看过的项数。

在 **设置 ▸ 通知** 中选择要通知的内容：全部关闭、选择类别（提问和回复、评审、失败、支出上限、已完成的作业）、播放声音、隐藏程序坞徽标，或关闭某个项目。收件箱中项目名称旁的铃铛（**将 … 的通知静音**）也可以将其静音，某一行**更多操作**菜单中的**将 … 的通知静音**同样可以；它的项目仍会显示在收件箱中。

同一事项在各处的表述都一样：收件箱中的行、它在实时看板上的卡片以及它的通知使用相同的标题，并用相同的措辞说明它为何在等待（例如 **已达到项目每日预算** · **工作已暂停** · **已花费 US$5.12 / US$5.00**）。

## 实时看板 {#live-board}

**实时看板**把所有项目的每一次运行集中在一处：轨道、循环、Intent 会话和作业。可从左侧边栏的**实时看板**、按 **Cmd+Shift+B**（Windows 和 Linux 上为 **Ctrl+Shift+B**），或在命令面板中选择**打开实时看板**来打开。它也是一个链接（`?live=1`），所以**后退**会关闭它。

用标题栏中的切换选择查看方式（会记住你的选择）：

- **按状态**：三列。**需要处理**正是收件箱列出的内容（可以决定的评审、问题、失败、被阻塞的运行、支出上限、Jira 更新），最早的在上，其数量就是收件箱的数量；每张卡片保留自己的状态指示灯，因此评审和问题很容易区分。列顶部的**打开待处理**会打开完整列表。**进行中**先列正在运行的，再列在队列中等待的，然后是已暂停的（带暂停指示灯）。**今日完成**列出今天完成、合并或停止的内容，午夜清空。一次运行只会出现在一列中。
- **按任务**：每个任务一行，包含它启动的所有运行、所属项目、引擎、运行数和今日支出。需要你处理的任务排在前面；不是由任务启动的运行排在最后的**非任务发起**中。

每张卡片显示运行的状态、轨道或类型（看板涵盖多个项目时还会显示项目）、标题、当前正在做什么、步骤（如有）、引擎、已运行或等待的时间，以及已知的成本。问题只显示一次其内容。会产生冲突的交付会显示一个简短标记（**2 个冲突**）；将指针悬停在上面或聚焦它即可阅读完整说明。卡片上的按钮与应用中其他地方的操作相同：**回答**、**打开评审**、**继续**、**重试**、**调高上限**，或**打开**——打开启动该运行的任务或运行本身。可按项目、类型（轨道、循环、Intent、作业）或引擎筛选；标题栏汇总需要你处理的数量和进行中的数量（即你所看到各列的计数），以及今日支出。

在桌面应用中，看板总是在单独的窗口中打开，方便放在第二块屏幕上：无论从哪里打开都会把这个窗口置于前台，**Cmd+Shift+B** 可显示或隐藏它。它的按钮（包括**打开待处理**）会在主窗口中执行，主窗口随之置于前台。

## 几个顺手的快捷键 {#shortcuts}

- **Cmd/Ctrl+B**——固定或收起左侧边栏；**Option+Cmd+B**（**Ctrl+Alt+B**）对右侧边栏执行相同操作。
- **Cmd/Ctrl+J**——切换终端面板。
- **Cmd/Ctrl+K**——命令面板：搜索任务、项目和 job，并**执行操作**。输入动词（如“新建”“启动”“移动”“切换”）或以 **>** 开头即可列出操作：新建 Spec（也可用探索模式）、启动或移动 Spec、打开其评审、交接或暂停 Intent、新建任务、切换主题、在任务模式与看板模式之间切换、在指定分区打开应用或项目设置、运行 Loop、切换侧边栏、后退或前进、撤销上一次更改，以及最近删除。需要选择的操作（Rail、状态、主题、分区）会打开第二页；搜索框为空时按 **Backspace** 返回。每个操作都会显示它的快捷键，面板因此也在教你按键。它只提供当前位置可用的操作，并遵守与按钮相同的规则（无法启动的 Spec 不会出现）。搜索为空时会列出你的**最近操作**和**最近位置**。
- **Cmd+[ / Cmd+]**（Windows/Linux 为 **Alt+← / Alt+→**）、标题栏中的 **←  →** 按钮，或鼠标的后退/前进键——在你去过的位置之间后退或前进：规格、任务、作业、项目和全屏面板。右键（或长按）按钮可查看最近的位置。
- **Cmd+Shift+I**（Windows 和 Linux 上为 **Ctrl+Alt+I**）或标题栏中的**待处理**按钮 —— **待处理**列表：把所有项目中等你处理的事项集中在一个按项目分组的列表里。它汇集了可以决定的评审、代理正在等待的提问、失败或被阻塞的运行、因每日预算而暂停的运行，以及未能同步的 Jira 更新。每一行有一个主要操作按钮（**打开评审**、**回答**、**继续**、**重试**、**调高上限**）；其余操作在它的**更多操作**菜单（**⋯**）中：**1 小时后提醒**、**明天再提醒**、**完成**、**标为已读**或**标为未读**，以及针对该项目的**将 … 的通知静音**。方向键在各行的主要按钮之间移动；**Tab** 可到达 **⋯**，方向键在菜单内移动，**Esc** 只关闭菜单。被推迟或已完成的事项一旦状态变化会自动回来。按钮会显示有多少项在等待；实时看板和命令面板显示的也是这个数字。服务商额度提示通知会打开该列表。该列表还是一个链接（`?inbox=1`），并且是命令面板中的一个操作。 它还会列出已暂停或在检查点等待的里程碑（**继续** / **继续下一步**），以及等待你决定的任务卡片：启动提议、Intent 提议或修复 CI 的提议（**打开任务**）。
- **M** — 在看板上聚焦某张规格卡片时,打开选择器把它移到某个状态或某条 Rail,相当于拖放的键盘版本。多选同样适用,命令面板中对应的是**移动聚焦的规格…**。
- **?** — 快捷键速查表。在它的搜索框里输入内容，可以筛选快捷键，并找到本指南中匹配的页面和章节，它们会直接在指南中打开，无需离开当前界面。设置、轨道、Intent、上下文滑块和预算旁边的小 **ⓘ** 图标和**了解更多**链接，也会以同样方式打开指南的对应章节。

## 下一步去哪儿

地形就摸到这儿。从这里出发，最自然的第一步是**添加一个 spec** 并在某条 rail 上启动它——看着流水线从头跑到尾，然后去 **分析** 里看看花了多少钱。欢迎上路。
