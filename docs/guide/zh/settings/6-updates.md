# 更新 {#updates}

Specrails 会保持两样东西为最新：**Specrails Desktop** 应用本身，以及项目使用的 **specrails-core** 框架。两者都在 **设置 ▸ 更新** 中。

## 更新通道

选择接收新版本的节奏：

- **最新**（默认）：每个版本发布后立即获取。最先获得新功能和修复。
- **稳定**：仅接收在最新通道上至少一周且 CI 通过、随后由维护者提升的版本。适合希望更新更少、更经过验证的团队。

通道同时适用于应用和 specrails-core。如果 specrails-core 尚无稳定版本，Core 暂时跟随最新，Core 卡片会提示这一点。

在稳定通道上，如果还没有任何版本被提升，**检查更新** 会明确告知，而不会提供最新通道的版本。

## 更新如何送达

- **Specrails Desktop** 在启动时和每 6 小时检查一次。有可用更新时会出现一张卡片，可在其中下载、安装并重启。也可以点击 **检查更新**。
- **specrails-core** 从不自动更新。在 Core 卡片上点击 **检查更新**，然后点击 **更新到（版本）** 进行安装。项目会切换到新框架，无需重启应用。

## 须知

- 从最新切换到稳定不会降级。你会停留在当前版本，直到稳定通道赶上。
- 两个通道上的每次更新都会在安装前进行签名验证。
