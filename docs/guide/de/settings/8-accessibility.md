# Barrierefreiheit und Anpassung {#accessibility}

Specrails passt sich an deine Arbeitsweise an. Alles steht unter **Einstellungen ▸ Darstellung**, gilt sofort und wird auf diesem Computer gespeichert.

## Dichte {#density}

**Komfortabel** hält Karten und Zeilen großzügig. **Kompakt** zeigt mehr auf einmal: Das Spec-Board startet als kompakte Zeilen, die Job-Liste nutzt engere Zeilen und die Job-Story verdichtet ihre Zeitleiste. Eine gespeicherte Board-Ansicht behält ihr eigenes Layout; eine als Haftnotizen gespeicherte Ansicht öffnet sich also weiterhin als Haftnotizen.

## Bewegung reduzieren {#reduce-motion}

**System folgen** respektiert dein Betriebssystem. **Reduzieren** schaltet Animationen und Übergänge in Specrails aus, was auch das System sagt: Die Rail-Pille bleibt an ihrer Position, Live-Punkte pulsieren nicht mehr und der Builder-Halo sowie die Theme-Effekte stehen still. **Volle Bewegung** animiert auch dann, wenn das System weniger verlangt.

## Eine Spec per Tastatur verschieben {#keyboard-moves}

Fokussiere eine Spec-Karte im Board (Tab oder Pfeiltasten) und drücke **M**. Eine kleine Auswahl listet die Status und die Rails; wähle mit den Pfeiltasten und **Enter**. Das entspricht dem Ziehen der Karte dorthin, auch bei Jira-gebundenen Specs, die über deinen Jira-Workflow verschoben werden. Gehört die Karte zu einer Mehrfachauswahl (**X** wählt die fokussierte Karte aus), gilt die Verschiebung für alle ausgewählten Specs. Die Befehlspalette bietet dasselbe als **Fokussierte Spec verschieben…**. **M** tut nichts, solange du in ein Feld tippst.

## Run-Meldungen für Screenreader {#live-status}

Specrails meldet Änderungen an Runs über einen höflichen Live-Bereich für das Projekt, das du gerade ansiehst: ein Run gestartet, pausiert, braucht dich, fehlgeschlagen, abgeschlossen oder mit bereitem Review. Schübe werden zusammengefasst und Wiederholungen verworfen, damit eine geschäftige Rail den Screenreader nie überflutet. Rückgängig-Hinweise melden sich bereits selbst.

## Tastaturfokus {#focus}

Jede Schaltfläche, jeder Link, jedes Menüelement, jede Karte und jede Baumzeile zeigt einen sichtbaren Fokusring, wenn du sie per Tastatur erreichst. Informationen, die früher nur in einem Tooltip standen, etwa die Spec-Referenz auf einem Rail-Streifen, stehen auch Tastatur- und Screenreader-Nutzern zur Verfügung.
