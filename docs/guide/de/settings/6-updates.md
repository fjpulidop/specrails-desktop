# Updates

Specrails hält zwei Dinge aktuell: die App **Specrails Desktop** selbst und das Framework **specrails-core**, das deine Projekte verwenden. Beides findest du unter **Einstellungen ▸ Updates**.

## Update-Kanal

Wähle, wie schnell du neue Versionen erhältst:

- **Neueste** (Standard): jede Version sofort nach der Veröffentlichung. Neue Funktionen und Korrekturen bekommst du zuerst.
- **Stabil**: nur Versionen, die mindestens eine Woche mit grüner CI auf Neueste liefen und danach von den Maintainern freigegeben wurden. Sinnvoll, wenn dein Team weniger, gut getestete Updates bevorzugt.

Der Kanal gilt für die App und für specrails-core. Hat specrails-core noch keine stabile Version, folgt Core vorerst Neueste, und die Core-Karte weist darauf hin.

Wurde auf Stabil noch keine Version freigegeben, meldet **Nach Updates suchen** das, statt eine Version von Neueste anzubieten.

## Wie Updates ankommen

- **Specrails Desktop** prüft beim Start und alle 6 Stunden. Ist ein Update verfügbar, erscheint eine Karte zum Herunterladen, Installieren und Neustarten. Du kannst auch auf **Nach Updates suchen** klicken.
- **specrails-core** aktualisiert sich nie von selbst. Klicke auf der Core-Karte auf **Nach Updates suchen** und dann auf **Aktualisieren**. Deine Projekte wechseln ohne Neustart der App zum neuen Framework.

## Gut zu wissen

- Ein Wechsel von Neueste zu Stabil stuft dich nie herab. Du bleibst auf deiner Version, bis Stabil aufholt.
- Jedes Update wird auf beiden Kanälen vor der Installation signiert und geprüft.
